title: Site analytics
description: What this documentation site and its live demos record.
---

The **react-broadcast-sync library collects no telemetry**. This documentation site and the live demos (`/demos/hook/`, `/demos/provider/`) do record anonymous usage analytics so the maintainer can see which pages and examples are useful. This is separate from the library.

## Docs site

- Clicks on top-nav and sidebar items (which item).
- Previous/next page navigation (from page, to page).
- Searches (the text you type, first 100 characters, sent after you stop typing) and clicks on search results.

## Demos

- Each action you take in a demo (for example increment, add a todo, send a notification, ping) and whether the demo uses the hook or the provider.
- The text you type into demo fields (text sync, todos, notifications) is sent, first 100 characters. Reaction emoji and notification severity are sent too.

## Privacy

- Events go to Mixpanel's EU endpoint with IP geolocation turned off.
- No cookies, no localStorage or sessionStorage. A random ID is generated on each page load, is never stored, and changes on every visit, so visits cannot be linked.
- Mixpanel still receives standard request metadata (such as IP address) as part of any web request; see [Mixpanel's privacy policy](https://mixpanel.com/legal/privacy-policy/).
- Because search text is free text, do not type personal information into the search box or the demo text fields.
- Ad blockers will stop these requests; nothing breaks if they are blocked.
