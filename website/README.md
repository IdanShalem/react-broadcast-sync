# react-broadcast-sync docs site

Documentation site for [react-broadcast-sync](https://github.com/IdanShalem/react-broadcast-sync), built with [Starlight](https://starlight.astro.build/) (Astro).

## Commands

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Deployment

Deployed on Vercel as its own project with the root directory set to `website/`.
